# atlante-data

Public data for the Atlante anatomical atlas apps (iOS/iPadOS/Mac and Android): 3D packages, names, descriptions, views and `manifest.json`,
published as GitHub Releases. Licence: CC BY-SA 4.0 — see [NOTICE.md](NOTICE.md) for sources and attribution.
Download `manifest.json` from the latest release to find packages, sizes and SHA-256 checksums.
